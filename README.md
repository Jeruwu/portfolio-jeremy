# Personal Portfolio Site 🚀

A bilingual (English/Spanish) Single Page Application (SPA) built to showcase projects, skills, and professional experience. Developed with a strong focus on type safety, smooth animations, and web accessibility.

🔗 **Live Demo:** [https://fancy-sawine-74018a.netlify.app](https://fancy-sawine-74018a.netlify.app)

## ✨ Key Features

* **Custom i18n System:** Engineered a type-safe internationalization system from scratch handling English and Spanish, utilizing Framer Motion's `AnimatePresence` for seamless locale transitions without relying on heavy external libraries.
* **Advanced Animations:** Implemented scroll-linked animations, spring physics, and 3D card transforms using Framer Motion to create an engaging user experience.
* **Accessibility First:** Strictly adheres to accessibility best practices, including semantic HTML structure, proper `aria-labels`, full keyboard navigation, and `prefers-reduced-motion` compliance for users sensitive to animations.
* **Fully Responsive:** Optimized for all screen sizes using Tailwind CSS.

## 🛠️ Tech Stack

* **Core:** React 18, TypeScript
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Build Tool:** Vite
* **Deployment:** Netlify

## 💻 Local Development

To run this project locally, follow these steps:

1. Clone the repository:
```bash
   git clone [https://github.com/jeremycanarte/portfolio.git](https://github.com/jeremycanarte/portfolio.git)
   ```
2. Navigate to the project directory:
```bash
   cd portfolio
   ```
3. Install dependencies:
```bash
   npm install
   ```
4. Start the development server:
```bash
   npm run dev
   ```
